# Every.to:一家媒体如何把自己改造成 AI 公司

**对 every.to 全站 2,235 篇内容逐篇取元数据后的结构拆解与内容演变分析 —— 一个「边自己用 AI 干活、边把它写成内容卖订阅」的样本。**

- 数据采集:2026-09-20(全部只读访问公开页面与公开接口)
- 方法:官方 sitemap(2,462 URL)+ 逐篇 `.md` front-matter + HTML meta 兜底 + MCP 协议交互 + RSS 交叉验证
- 有效样本:**2,176 篇带发布日期**(另 59 篇为指南/观点合集,无发布时间字段)

---

## 一、它是什么

Every 是「媒体 + AI 产品」的混合体。2015–2022 年它是一个多栏目出版网络(生产力、商业分析、创作者经济、心理);2023 年起整体转向 AI,如今既出版内容,也售卖自己的 AI 工具(Spiral、Cora 等)与 agent 工作流。

最反直觉的一点:**前端是常规 Next.js 杂志站(正文走客户端渲染),后端却专门给 AI 读者开了三条通道** —— Markdown 直出、`llms.txt`、MCP 端点。这是一个明确"为 AI 消费而设计"的出版站。

### 为 AI 读者设计的四条通道

| 通道 | 说明 |
|---|---|
| `/<pub>/<slug>.md` | 直出 Markdown + YAML front-matter(title/subtitle/description/authors/publication/published_at/tags/audience) |
| `/llms.txt` · `/llms-full.txt` | 后者 434 KB,含 47 篇全文,可直接做知识库种子 |
| `POST /mcp` | MCP 端点,暴露 `public_feed_tool` / `public_get_post_tool` / `public_search_tool`,匿名可用 |
| `/feeds/global.xml` | 全站 RSS(最新 50 条) |

> **采集时踩到的坑**
> ① 文章页是 CSR,直接抓 HTML 拿不到正文;
> ② 未知路径一律返回 200,不能靠状态码判断存在;
> ③ `vibe-check` / `thesis-statements` / `guides` 三个新栏目的 `.md` 不生效,会回落成 HTML(需改用 HTML meta 或 MCP);
> ④ 栏目级 `/feeds/<col>.xml` 是空 feed。

## 二、转折曲线:AI 占比从 2% 到 91%

| 年份 | AI 相关 / 总数 | 占比 |
|---|---|---|
| 2020 | 8 / 372 | 2% |
| 2021 | 14 / 321 | 4% |
| 2022 | 42 / 273 | 15% |
| **2023** | **97 / 300** | **32%** |
| **2024** | **206 / 290** | **71%** |
| 2025 | 255 / 301 | 85% |
| 2026 | 206 / 226 | 91% |

**结论:2023 是转型元年,2024 才是分水岭。** 2023 年仍有三分之二内容在写旧主题(生产力、商业分析、心理);真正"全面 AI 化"发生在 2024 年(71%),此后逐年抬升。

## 五、2023 年那 97 篇,具体写了什么

### ① 1–4 月:GPT-3/4 的「个人用法」实验

- **拿自己当实验品**:用 GPT-3 记日记与自我分析,配代码开源
- **让 AI 帮写作**:从"AI 代笔指南"到"让 AI 模仿你喜欢的作家",并做成付费工作坊
- **教学产品化**:教人用 GPT-3 造 chatbot、把 GPT-4 当"心智副驾"
- **商业判断**:泡沫论、LLM 是"新 CPU"、OpenAI 是否下一个巨头、今天能做的五类 AI 产品
- **情绪面**:敬畏、焦虑、以及"允许自己为 AI 兴奋"

### ② 5–8 月:AI 杀进具体职业

- **金融**:GPT-4 当"新来的财务实习生"、代码解释器将重塑财务、AI 已能构建交易策略
- **编程**:AI 与编程的未来、教 100 人用 AI 学写代码的复盘
- **日常**:让 AI 处理邮件、用"蠢工具"自动化琐事
- **工具与图像**:GPT-4 学会用工具意味着什么、Midjourney 使用指南
- **媒体**:AI 将永久改变媒体

### ③ 9–12 月:从「玩工具」到「建体系」

- **OpenAI DevDay 现场**:连发三篇现场报道,其中一篇以"奥特曼已死,奥特曼万岁"写权力风波
- **新栏目上线**:11 月 14 日推出 `ai-and-i`(《How Do You Use ChatGPT?》)—— 从此"采访别人怎么用 AI"成为固定产品线,并在 2024 年成为 AI 内容第一大栏目(56 篇)
- **商业化**:生成式 AI 产品如何定价、数据与算力才是终极飞轮
- **职业冲击**:"高绩效者的最后一份工作"、"你现在是开发者了"
- **前瞻**:SaaS 之后是什么、聊天是否是 AI 的未来、跨过 AI 卢比孔河

### ④ 贯穿全年

`chain-of-thought`(42 篇)是主阵地,`sunday-digest`(19 篇)做每周聚合,`napkin-math`(13)与 `divinations`(8)从商业视角切入。

## 六、五条关键洞察

1. **「转向」不是一次决定,而是一条 7 年曲线。** 从 2%(2020)到 91%(2026),没有跳变,只有每年抬升 15–40 个百分点。2023 被误认为拐点,其实只是第一次"过半前"的显著值(32%)。
2. **内容栏目与商业产品同构。** `ai-and-i`(2024)→ `source-code`(2025)→ 自家 agent 产品,顺序是"先看别人怎么做 → 再拆自己怎么做 → 最后卖工具"。媒体栏目本身就是产品路线图。
3. **模型评测取代了科技新闻。** 2025–2026 年"模型评测"主题累计 122 篇(其中 `Vibe Check` 栏目 48 篇),把"新模型上手体验"做成可复用栏目 —— 这是 AI 时代最稳定的流量与订阅抓手。
4. **注意力从"我"转向"用"。** "AI 与个人成长/心理"从 17 篇(2024)降到 3 篇(2026);"行业思想观点"从 17 篇降到 0。
5. **它把自己变成了 AI 原生出版站的样本。** `.md` 直出 + `llms-full.txt` + 匿名 MCP 端点 —— 内容不只是给人读,也主动喂给 AI。这与"内容 + AI 产品"的商业模式互为支撑。

## 七、方法、口径与已知缺口

| 步骤 | 做法 |
|---|---|
| URL 全集 | 官方 sitemap 三份合并去重 → 2,462 条,按路径形态分类 |
| 发布日期 | 逐篇请求 `/<pub>/<slug>.md`,解析 front-matter 的 `published_at`(并发 8–10,全量约 4.5 分钟) |
| 兜底 | 59 篇新栏目文章 `.md` 不生效 → 改用 HTML 的 `article:published_time` / JSON-LD |
| 交叉验证 | RSS 与 sitemap 日期一致性抽查;文章页 HTML 与 `.md` 元数据抽查 |
| AI 判定 | 标题 + 副标题正则命中(AI/agent/LLM/GPT/Claude/model/prompt/vibe 等),仅作趋势统计 |
| 主题归桶 | 互斥优先级规则,同一篇只入一桶 |

**已知缺口(诚实标注)**

1. `thesis-statements` 52 条与 `guides` 部分条目**没有发布日期字段**,已排除在年份曲线外,但已收进主题清单;
2. `thesis-statements` 是以作者名为 slug 的「After automation」观点合集(52 位作者各一条),属栏目而非独立文章;
3. 未知路径一律返回 200,"页面存在性"以元数据是否可解析为准,而非状态码;
4. AI 占比基于标题命中,是**趋势下界**(正文谈 AI 但标题未提的未被计入)。
